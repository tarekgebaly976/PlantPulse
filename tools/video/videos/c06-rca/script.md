# PlantPulse cartoon – root cause analysis

| Scene | Shown | Narration (one line per step) |
|---|---|---|
| 01-rule | anim | The grinding mill stops again. High vibration, for the third time this month.<br>The plant's rules say what a major breakdown is: downtime for the criticality, repeats, production loss, cost, or a safety event. This one matches, so PlantPulse proposes a root cause analysis.<br>The manager decides. Start it, with a leader, a team and a due date, or mark it not required, with a reason. |
| 02-why | anim | The team investigates, tab by tab. First, the problem in five W's and one H, filled in from the work orders.<br>The fishbone sorts the possible causes: man, machine, method, material, measurement and environment.<br>Then the five whys. Keep asking why, until the last why is the root cause.<br>The root causes are recorded as physical, human and system. |
| 03-act | anim | The action plan: containment, corrective and preventive actions, each with an owner and a due date. The manager approves it, or returns it with a note.<br>The owners carry out their actions, with the result as evidence. An action can raise its own work order; completing the work order completes the action. |
| 04-check | anim | When the last action is done, the effectiveness check starts. If the same failure comes back, the analysis reopens by itself.<br>Print report puts the whole analysis on one page, and the register of all analyses exports to Excel. |
| 05-end | anim | Find the root, fix it, and prove it worked. Next: production, the daily report and OEE. |
